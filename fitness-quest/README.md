# フィットネスクエスト V3

妻さんの健康をサポートするゲーミフィケーション運動アプリです。

## 機能

✨ **回数ベースのチャレンジ** - 腕立て伏せ50回などの目標を達成してレベルアップ
💡 **AI相談機能** - 「今日は何しよう？」と聞くと、AIが次のトレーニングを提案
👑 **バッジシステム** - チャレンジを達成するたびにバッジを獲得
💬 **応援メッセージ** - 夫さんから応援メッセージを送信可能

## ファイル構成

```
fitness-quest/
├── package.json         ← こっちはそのまま
├── next.config.js       ← こっちはそのまま
├── app.js               ← これをフォルダ構造に入れます ⬇️
├── デプロイ手順.md
└── README.md
```

## セットアップ（重要！）

このファイル（app.js）は以下のフォルダ構造に配置します：

```
fitness-quest/
├── package.json
├── next.config.js
├── pages/
│   └── index.js         ← app.js をここにコピー&ペーストして、
│                           ファイル名を index.js に変更
├── デプロイ手順.md
└── README.md
```

### 手順

1. `fitness-quest` フォルダを作成
2. `package.json` と `next.config.js` をそこに入れる
3. `pages` フォルダを作成
4. `app.js` を `pages/index.js` にコピー（ファイル名を変更）

できたら、「デプロイ手順.md」を読んでください！

## 最初に試す

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いて動作確認

## デプロイ

最も簡単な方法は GitHub + Vercel です。

## 使い方

### 妻さん用
1. アプリを開く
2. チャレンジを選択（例：腕立て伏せ 50回）
3. 達成した回数を入力して「完了」
4. 「今日は何しよう？」で AI に相談

### 夫さん用
1. 「夫モード」をクリック
2. 妻さんの進捗をチェック
3. 応援メッセージを送信

## カスタマイズ

チャレンジの内容を変更したい場合は、`pages/index.js` の以下の部分を編集：

```javascript
const challengeTemplates = [
  { id: 'pushups_50', name: '腕立て伏せ', target: 50, icon: '💪', level: 1 },
  // ここに新しいチャレンジを追加
];
```
