# フィットネスクエスト V3 - Vercel デプロイ手順

## 最も簡単な方法（推奨）：Vercel CLI を使用

### 1. 準備
- Node.js をインストール（https://nodejs.org/）
- Vercel アカウントを作成（https://vercel.com/signup）

### 2. デプロイ手順

```bash
# 1. まずこのファイルたちをフォルダに入れる
# 例: C:\Users\あなたの名前\fitness-quest フォルダを作成

# 2. コマンドプロンプト or ターミナルで以下を実行
npm install -g vercel

# 3. プロジェクトフォルダに移動
cd fitness-quest

# 4. Vercel にログイン
vercel login

# 5. デプロイ
vercel

# 質問に答える（Enter キーで続ける）
```

### 3. デプロイ後
- Vercel が自動的に URL を生成します
- その URL をスマートフォンで妻さんに共有すれば完了！
- 例：`https://fitness-quest-12345.vercel.app`

---

## 別の方法：GitHub を使用（より簡単）

### 1. GitHub で無料アカウント作成
- https://github.com/signup

### 2. リポジトリを作成
1. GitHub にログイン
2. 「New repository」をクリック
3. リポジトリ名：`fitness-quest`
4. 「Create repository」

### 3. ファイルをアップロード
- コード欄の「Add file」→「Upload files」
- このフォルダのすべてのファイルをドラッグ&ドロップ
- 「Commit changes」をクリック

### 4. Vercel と GitHub を連携
1. https://vercel.com/new にアクセス
2. 「Import Git Repository」
3. GitHub リポジトリを選択
4. 「Deploy」をクリック

### 5. 完了！
- 自動的にデプロイされ、URL が生成されます
- その URL を妻さんに共有

---

## ローカルで試す方法（デプロイする前に確認したい場合）

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開くと、ローカルで動作確認できます

---

## トラブルシューティング

**「npm コマンドが見つからない」**
→ Node.js を再インストール後、パソコンを再起動

**「vercel コマンドが見つからない」**
→ PowerShell の場合、別のターミナルで `npm install -g vercel` を再実行

**ビルドに失敗する**
→ package.json と app.js のファイル名が正しいか確認

---

## 妻さんが使う方法

1. 夫さんから URL を受け取る
   例：`https://fitness-quest-xxxxx.vercel.app`

2. スマートフォンのブラウザでその URL を開く

3. アプリが起動！
   - チャレンジを選択して、回数を入力して「完了」
   - 「今日は何しよう？」で AI に相談
   - 進捗がリアルタイムで更新される

---

## 妻さんのデータについて

- すべてのデータはスマートフォンのブラウザに保存（ローカルストレージ）
- クラウドには保存されないため、プライバシーは完全に保護されます
- 別のブラウザやシークレットモードでは、別のデータが保存されます
- データをバックアップしたい場合は、別途ご相談ください

---

## カスタマイズ

チャレンジの内容を変更したい場合は、app.js の以下の部分を編集：

```javascript
const challengeTemplates = [
  { id: 'pushups_50', name: '腕立て伏せ', target: 50, icon: '💪', level: 1 },
  // ここに新しいチャレンジを追加
];
```

編集後は、GitHub にアップロードすると自動的に反映されます。
